# Fluent UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Заменить функциональный Qt Quick-каркас Tweakopedia на утверждённую светлую Fluent 2-оболочку с адаптивной левой навигацией, бинарными тогглами и явной подсветкой очереди.

**Architecture:** Приложение использует `QtQuick.Controls.Basic` и собственный набор небольших QML-компонентов, питающихся семантическими ролями C++-моделей. Категории загружаются из существующего `content/categories.yaml`, а поиск и фильтрация выполняются отдельной proxy-моделью. Существующий исполнительный и транзакционный контур не меняется.

**Tech Stack:** C++20, Qt 6.8.3 Core/Gui/Qml/Quick/QuickControls2/Test, QML, Qt Test, CMake 3.30.5, Ninja 1.12.1.

**Spec:** `docs/superpowers/specs/2026-10-08-fluent-ui-single-exe-design.md`

## Global Constraints

- Только светлая тема; токены и размеры берутся дословно из раздела 5 спецификации.
- Windows 10/11 x64; ARM64 не добавляется.
- Бинарный тоггл изменяет только очередь и никогда не вызывает Executor напрямую.
- Фактическое состояние остаётся отдельным от целевого во всех C++ и QML-моделях.
- Слова `включено` и `выключено` всегда видимы; цвет не является единственным признаком состояния.
- UI Kit не зависит от сторонней Fluent-библиотеки и не копирует исходники UCC-Revorked.
- Верхние вкладки удаляются; основная навигация слева: 220 px при ширине от 1100 px и 64 px ниже порога.
- `?` открывает dock-панель на широком окне и overlay-панель на узком.
- Все новые тестовые и временные файлы направляются под `D:\ChatGPT` процессными переменными.
- Каждый task выполняется через RED → GREEN → полный профильный прогон → отдельный commit.

## Review Focus

- Неизвестное или неподдерживаемое состояние: строка остаётся читаемой, тоггл недоступен и очередь не меняется; покрывается Task 4.
- Быстрые повторные переключения: очередь содержит не более одной цели, а возврат к фактическому состоянию удаляет её; покрывается Task 2 и Task 4.
- Порог 1099/1100 px, длинные русские названия и масштаб 150%: элементы не перекрываются и основные команды остаются доступны; покрывается Task 7 и Task 9.
- Закрытие панели пояснения клавишей Esc: фокус возвращается к исходной кнопке `?`; покрывается Task 8.
- Пустые каталог, очередь и история: страницы показывают осмысленные empty states без пустых рамок и недоступных основных команд; покрывается Task 9.
