# Навигация по результатам диагностики сети

## Назначение

Привести просмотр результатов диагностики к уже знакомому пользователю паттерну раздела «Твики»: вертикальный список объектов и отдельная правая панель подробностей.

## Контракт интерфейса

- Результаты выводятся одним вертикальным списком без карточной сетки.
- Каждая строка содержит пиктограмму состояния, название, краткий итог и текст состояния.
- Выбранная строка остаётся визуально выделенной, пока открыта панель подробностей.
- При ширине окна от 1180 px панель шириной 420 px закрепляется справа, а основное содержимое освобождает ей место.
- На меньшей ширине панель выезжает поверх страницы и закрывается кликом вне панели или клавишей Escape.
- Подробности, найденные правила Windows Firewall, подтверждение удаления и результат операции остаются внутри панели.
- Клавиатурный фокус и доступные имена сохраняются для строк, закрытия панели и действий.

## Состояния

- До запуска: список отсутствует, остаётся исходное приглашение запустить диагностику.
- Выполнение: структура страницы стабильна, отображаются этап и индикатор.
- Успех или частичный результат: список содержит все доступные блоки; недоступные данные явно отмечены.
- Ошибка: остаются сообщение и повторный запуск.
- Удаление правила: подтверждение, блокировка параллельных действий и итог операции отображаются без потери выбранного блока.

## Контрольные размеры

- Широкий: 1280 × 800.
- Узкий: 720 × 760.
