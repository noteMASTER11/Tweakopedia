# Блокировка телеметрии — спецификация

## Назначение

Инструмент формирует понятный пакет ограничений из твиков, уже присутствующих в
каталоге Tweakopedia. Он не содержит второго набора команд: обнаружение,
предварительный план, применение, журнал транзакции и возврат исходных значений
остаются общими для приложения.

## Профиль

Первая версия предоставляет один сбалансированный профиль:

- минимальный общеупотребимый уровень диагностических данных;
- исключение имени компьютера из диагностических событий;
- отключение запросов отзыва, OneSettings и конфигурационных экспериментов;
- отключение персонализации по диагностическим данным и рекламного идентификатора;
- отключение Activity Feed и передачи действий между устройствами;
- отключение сбора образцов ввода и связанной персонализации.

Профиль не меняет WER, обновления, учётную запись Microsoft, Windows Hello,
Xbox, службы и разрешения приложений. Файл `hosts` и сетевые адреса не меняются:
непрозрачная доменная блокировка может затронуть несколько несвязанных функций.

## Пользовательский сценарий

Экран показывает каждый включённый в профиль твик, фактическое и целевое
состояния, совместимость и наличие изменения в очереди. По карточке можно перейти
к обычному экрану твика и прочитать его статью.

Кнопка «Добавить в очередь» добавляет только поддерживаемые и ещё не настроенные
пункты. Она не применяет их немедленно. После этого пользователь открывает
очередь, проверяет пересчитанный план и применяет пакет стандартным способом.

## Ограничения

- значение `AllowTelemetry=0` не навязывается редакциям Windows, где оно не
  обеспечивает полного отключения; профиль выбирает обязательный уровень;
- неподдерживаемые текущей сборкой пункты отображаются, но не добавляются;
- уже выбранное для того же твика значение заменяется целевым значением профиля;
- возврат выполняется по журналу общей транзакции, без отдельного механизма.
