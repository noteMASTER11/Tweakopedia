## TDD и аудит содержимого

Сначала `TweakCatalogLoaderTest` был изменён для ожидания 685 записей и завершился
ошибкой на прежнем каталоге из 535 записей. После добавления содержимого проверены
репрезентативные ID, значения `Attributes`, состояния политик питания и точное
число новых пунктов.

При проверке EXE выявлено ограничение распаковщика на чрезмерно длинные имена
YAML-файлов. Физические имена 145 файлов сокращены до GUID параметров, а
постоянные человекочитаемые ID внутри определений сохранены. В тест каталога
добавлено ограничение длины имени файла.

Также кэш runtime теперь повторяет чтение и карантин при кратковременной
занятости файлов. Два теста воспроизводят временную блокировку корректного и
повреждённого runtime.
