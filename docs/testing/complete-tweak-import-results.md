- Выпуск собирается только для x64.
- 72 заголовка документации Winaero оставлены вне каталога: их описание не
  задаёт однозначный объект и исполняемое значение.
- Операции с офлайн-кустом `HKU\Default` не импортированы.
- Удаление деревьев реестра без восстановимого исходного содержимого не
  импортировано.
- Параметризованные команды питания и команды, зависящие от изменяемой активной
  схемы, не импортированы.
- Управление службами исключено по решению владельца проекта.
- Очистка данных и произвольные PowerShell/CMD-сценарии не преобразуются в
  операции каталога.
