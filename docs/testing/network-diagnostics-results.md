# Проверка инструмента диагностики сети

Дата: 13 октября 2026 года.

## Покрытие

- фиксированный запуск Windows PowerShell 5.1 через системный путь;
- отсутствие пользовательских параметров и операций изменения конфигурации;
- шесть независимых блоков: адаптеры, DNS, прокси/PAC, `hosts`, маршруты и
  Windows Firewall;
- потоковый UTF-8, разбиение JSON-маркеров между порциями и их исключение из
  терминальной области;
- подавление Progress PowerShell и восстановление маркера из CLIXML-строки без
  показа XML в терминале;
- типизированные результаты `ok`, `attention` и `unavailable`, общий итог и
  сохранение результатов при сбое отдельного блока;
- ограничение деталей маркеров и экранного буфера 2 МиБ;
- IPC Executor, отмена UAC, ошибки запуска, журнал сеанса и изоляция событий
  чужого запроса;
- QML-маршрут, состояния, счётчики, адаптивная сетка, терминал и переход к
  инструменту восстановления;
- клик по каждой карточке, полная панель подробностей и сохранение выбранной
  карточки после закрытия панели;
- структурированный список пользовательских правил Windows Firewall;
- отдельное подтверждение удаления, проверка ключа по последнему результату,
  Base64-передача данных, экспорт `.wfw`, точное удаление одного правила и
  изоляция событий чужого запроса;
- включение страницы в ресурсы и однофайловую portable-упаковку.

## Проверки

Встроенный PowerShell-сценарий дополнительно выполнен на текущей Windows в
режиме чтения: код завершения `0`, получены маркеры всех шести блоков.

```powershell
$env:TEMP='D:\ChatGPT\Temp\Tweakopedia'
$env:TMP=$env:TEMP
cmake --build build/mingw-debug
ctest --test-dir build/mingw-debug --output-on-failure
pwsh -NoProfile -File .\tools\package.ps1
pwsh -NoProfile -File .\tools\verify-package.ps1 `
  -PackagePath D:\ChatGPT\Projects\Tweakopedia\dist\Tweakopedia.exe
```
