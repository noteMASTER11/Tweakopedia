# Проверка инструмента файловой системы

Дата: 13 октября 2026 года.

## Покрытие

- обнаружение локальных готовых томов NTFS через подменяемый Win32-слой;
- фильтрация сетевых, оптических, неподготовленных и неподдерживаемых томов;
- строгая цель вида `^[A-Z]:$` и точная команда `chkdsk.exe <буква>:`;
- отсутствие ключей `/F`, `/R`, `/X`, `/B` и `/spotfix`;
- отображение кодов завершения `0`, `2`, `3`, `1` и неизвестных кодов;
- потоковый вывод, журнал сеанса и ограничение экранного буфера 2 МиБ;
- общий IPC с DISM без смешивания событий контроллеров;
- отмена UAC, исчезновение процесса, повторный запуск и действия с журналом;
- QML-навигация, выбор тома, состояния, терминал и узкая компоновка;
- однофайловая portable-упаковка и изолированный self-check.
