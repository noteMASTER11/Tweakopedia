# Fluent UI visual checklist

Проверять `wide.png` и `narrow.png` при масштабах 100%, 125% и 150%.

- Левая навигация развёрнута при 1280 px и компактна при 960 px.
- Заголовки и длинные русские строки не обрезаны и не перекрывают тогглы.
- `Сейчас:` и `После применения:` остаются видимыми; состояние выделено цветом и насыщенностью.
- Изменённая строка имеет фон, левую полосу и метку `Изменено`.
- Панель пояснения помещается справа в широком варианте и отсутствует в узком fixture.
- Нижняя команда очереди видима и не перекрывает каталог.
- Основная кнопка полностью видима при каждом масштабе.
- Фон, поверхности, границы и основной текст соответствуют токенам `FluentTheme`.

## Твикопедия

- При 1440 px видны дерево статей и правая панель содержания.
- При средней ширине дерево остаётся на месте, а содержание открывается кнопкой.
- При 900 px дерево заменяется кнопкой выдвижной панели, статья занимает доступную ширину.
- Длинный заголовок и технический путь переносятся внутри полотна без выхода за правую границу.
- Связанные статьи в узком режиме располагаются вертикально.
- Секционные карточки выровнены по высоте строк сетки; ячейки значков имеют одинаковый размер.
