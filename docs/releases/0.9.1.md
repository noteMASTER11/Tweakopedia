# Tweakopedia 0.9.1

Первый опубликованный выпуск автономной русскоязычной энциклопедии параметров
Windows и транзакционного твикера.

## Основные возможности

- 385 подробно описанных твиков для Windows 10 и Windows 11 x64.
- Определение фактического состояния параметров и фильтрация по версии ОС.
- Тогглы, выпадающие списки и отдельные действия для разных типов настроек.
- Очередь изменений с предварительным итогом перед применением.
- Снимок исходных значений, журнал транзакций, история и возврат изменений.
- «Твикопедия» с древовидным каталогом, полнотекстовым поиском, связанными
  статьями и переходом к соответствующему твику.
- Каталог из 141 идентификатора AppX-приложений с поиском установленных пакетов.
- Обзор компьютера: Windows, процессор, оперативная память, видеокарты,
  накопители, системная плата, BIOS и время работы.
- Адаптивный светлый интерфейс Fluent UI и встроенный шрифт SF Pro.

## Формат поставки

Программа поставляется одним portable EXE. При первом запуске Qt-runtime
извлекается в локальный кэш приложения; устаревшие версии кэша удаляются
автоматически.

Установка не требуется. Для применения системных изменений приложение запускает
отдельный Executor с повышенными правами.

## Каталог твиков

Параметры охватывают Проводник, рабочий стол и панель задач, вход в систему,
учётные записи, приватность, сеть, накопители, питание, устройства, игры,
Windows Update, системные компоненты, приложения и экспериментальные функции.

В заключительный пакет выпуска добавлены ещё 50 атомарных настроек для
Проводника, рекомендаций Windows, диагностики, совместимости приложений,
обновлений, RDP, графики и игрового режима.

## Техническая база

- C++20, Qt 6.8.3 и QML;
- CMake 3.30.5, Ninja 1.12.1 и MinGW 13.1.0;
- yaml-cpp для каталога, SQLite для истории и miniz для встроенного payload;
- Win32 API, WMI и DXGI для интеграции с Windows и паспорта компьютера.

## Ограничения

- Поддерживается только архитектура x64.
- Интерфейс доступен на русском языке и только в светлой теме.
- Цифровая подпись EXE пока не настроена.
- Автоматическое восстановление удалённого AppX-пакета не реализовано.
- Доступность некоторых параметров зависит от редакции и сборки Windows.
- Для отдельных изменений требуется выход из учётной записи, перезапуск службы
  или перезагрузка компьютера.
