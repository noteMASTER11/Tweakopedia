# Tweakopedia 0.9.4

Выпуск добавляет тематическую навигацию внутри категорий и приводит
типографику приложения к системному стилю Fluent UI на обычных и HiDPI-дисплеях.

## Навигация по твикам

- Существующие подкатегории YAML представлены однострочной горизонтальной
  лентой над карточками твиков.
- Лента поддерживает колесо мыши, горизонтальные жесты тачпада и круглые кнопки
  перехода к соседним группам.
- В широком режиме лента совпадает по ширине с колонкой карточек и не создаёт
  отступа в вертикальном списке категорий.
- В узком режиме вкладки остаются одной прокручиваемой строкой.
- Для «Все категории» и первичного поиска установленных приложений лента
  скрывается без резервирования пустого места.
- Переход из Твикопедии автоматически выбирает категорию и группу нужного твика.

## Каталог и фильтрация

- Добавлена проверка ссылок `category/subcategory` для всего каталога.
- Пустые и неизвестные группы обнаруживаются до показа каталога.
- Группы сохраняют порядок из `categories.yaml` и учитывают фильтр
  неподдерживаемых параметров.
- Поиск, категория, тематическая группа и совместимость работают как единый
  фильтр списка.

## Типографика

- Удалён встроенный SF Pro; приложение использует системный `Segoe UI Variable`
  или `Segoe UI` с резервным системным шрифтом Qt.
- Введён единый текстовый компонент с нативной растеризацией, вертикальным
  hinting и типографическими метриками Qt 6.8.
- Сохранены отдельные семейства для Fluent-иконок и моноширинного технического
  текста.
- Проверены русские и смешанные строки при масштабах 100%, 125%, 150% и 200%.

## Проверка выпуска

- Поддерживаемые платформы: Windows 10/11 x64.
- Формат: один portable EXE с локальным версионированным runtime-кэшем.
- Полный набор из 72 CTest-сценариев пройден.
- Изолированная проверка single-EXE выполнена.
