# Tweakopedia 0.9.2

Выпуск расширяет каталог на 300 пунктов: с 385 до 685 твиков. Основная тема
версии — системные политики Windows и расширенные параметры электропитания.

## Новые твики

- 145 переключателей видимости расширенных параметров электропитания и 5
  регулируемых политик схем питания.
- Microsoft Defender, SmartScreen и политики Microsoft Edge.
- Установка устройств, съёмные носители и печать.
- Проводник, Windows Search и системное поведение.
- Remote Desktop Services, вход в систему и запуск приложений.
- Windows Error Reporting и связанные системные политики.

Каждый новый пункт содержит русское описание, проверку применимости к версии
Windows, фактическое определение состояния и обратную операцию.

## Интерфейс

- После успешного применения появилась кнопка «Вернуться к твикам» с возвратом
  в исходный раздел и позицию списка.
- Исправлены размеры, отступы и состояние наведения карточек связанных статей
  в Твикопедии.

## Portable-контейнер

- Доработана обработка повреждённого или устаревшего runtime-кэша.
- Устранены ошибки запуска `Cannot quarantine invalid runtime` и
  `Cannot create extracted file`.
- Добавлены повторные попытки очистки и восстановления runtime при временной
  блокировке файлов.

## Проверка выпуска

- Поддерживаемые платформы: Windows 10/11 x64.
- Формат: один portable EXE, который извлекает Qt runtime в локальный кэш.
- 47 из 47 CTest-сценариев пройдены.
- Изолированный запуск EXE без Qt и MinGW в `PATH` пройден.
- SHA-256: `bd774de15eb7e44f7c16e804e2d8c160f5501826139892a02751d69eefd38cfe`.
