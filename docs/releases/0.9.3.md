# Tweakopedia 0.9.3

Выпуск завершает полный типизированный импорт доступных твиков из изученных
проектов и увеличивает каталог с 685 до 1109 определений.

## Каталог

- Добавлено 418 твиков: 391 операция со значениями реестра, 10 задач
  планировщика, 11 параметров схем питания, 3 элемента BCD и 3 Optional Feature.
- Проверено 3676 исходных кандидатов; для каждого сохранено решение в audit-manifest.
- Добавлены значения реестра типов `QWORD`, `SZ`, `EXPAND_SZ`, `MULTI_SZ` и
  `BINARY`, значения по умолчанию и ограниченные деревья реестра.
- Добавлены шесть отдельных редакторов OEM-сведений, включая BMP-логотип.

## Исполнение и возврат

- Реализованы типизированные исполнители задач планировщика, BCD, параметров
  питания, компонентов Windows, файлов и расширенных операций реестра.
- Расширены снимки транзакций, повторная проверка состояния и обратный порядок
  возврата для смешанных пакетов.
- Произвольные строки PowerShell и CMD в план выполнения не допускаются.

## Интерфейс

- Добавлены Fluent-редакторы текста, чисел, файлов и именованных вариантов.
- Исправлена постановка изменений из выпадающих списков в очередь.
- Добавлен раздел «Настройки» с режимом отладки и открытием каталога журналов.
- Очередь показывает конкретные значения параметризованных твиков.
