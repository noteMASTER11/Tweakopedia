# Tweakopedia

Tweakopedia — автономная русскоязычная энциклопедия параметров Windows и
транзакционный твикер. Программа объясняет назначение каждого параметра,
показывает его фактическое состояние, собирает выбранные изменения в очередь и
применяет их только после просмотра итогового плана.

Проект рассчитан на Windows 10 и Windows 11 x64. Интерфейс написан на Qt 6 в
светлом стиле Fluent UI; приложение распространяется одним portable EXE и не
требует установки.

> **Статус проекта:** версия 0.9.3 содержит 1109 типизированных твиков и расширенный транзакционный исполнитель.
> Каталог и исполнитель уже пригодны для практического использования, но перечень
> твиков и проверки совместимости продолжают расширяться.

## Возможности

- Каталог параметров Windows с поиском, категориями и тематическими значками.
- Автоматическое определение текущего состояния поддерживаемых твиков.
- Проверка совместимости по семейству Windows, номеру сборки и архитектуре.
- Флажок для скрытия неподдерживаемых твиков и автоматически пустеющих разделов.
- Тогглы для бинарных параметров, выпадающие списки для именованных состояний и
  отдельные команды для действий вроде удаления приложения.
- Подробная справка по клику на карточку: назначение, механизм, результат,
  ограничения, рекомендация, технические сведения и способ возврата.
- «Твикопедия» с древовидной навигацией, полнотекстовым поиском, связанными
  статьями и переходом из статьи к соответствующему твику.
- Очередь изменений: система не меняется в момент переключения элемента
  интерфейса.
- Предварительный план с исходными и целевыми состояниями.
- Пакетное применение с прогрессом и уведомлением о необходимости перезагрузки.
- История транзакций с раскрываемым перечнем конкретных операций.
- Возврат точных исходных значений реестра и пользовательских переопределений
  Windows Feature Store.
- Поиск установленных AppX-приложений перед показом вариантов удаления.
- Обзор компьютера: Windows, процессор, оперативная память, видеокарты,
  накопители, системная плата, BIOS и время работы.
- Редактирование OEM-сведений: производитель, модель, контакты поддержки и
  BMP-логотип.
- Режим отладки с отдельным журналом каждой сессии и быстрым открытием каталога
  логов.
- Адаптивная Fluent-навигация: полный сайдбар при широком окне и панель значков
  при узком.

Каталог версии 0.9.3 содержит 1109 YAML-определений твиков и справочник из 141
идентификатора приложений. Количество будет меняться по мере наполнения.

## Как устроено применение изменений

```text
Определение текущего состояния
            ↓
Выбор новых значений в интерфейсе
            ↓
Очередь и итоговый план
            ↓
Повторная проверка исходных значений
            ↓
Снимок транзакции
            ↓
Применение через отдельный Executor
            ↓
История и возможный возврат
```

1. Основной процесс считывает профиль ОС и текущее состояние параметров.
2. Действия пользователя попадают в очередь, не изменяя Windows немедленно.
3. Перед применением строится типизированный план. Произвольные команды из YAML
   не выполняются.
4. Executor повторно сравнивает исходное состояние с планом. Если оно успело
   измениться, операция прекращается.
5. До первой записи сохраняются фактические исходные значения и журнал
   транзакции.
6. Реестровые и Feature Store-операции при ошибке возвращаются в обратном
   порядке, если полный возврат для данного набора возможен.
7. Удаление AppX-пакета необратимо средствами Tweakopedia: для возврата
   приложение потребуется установить заново.

## Разделы приложения

| Раздел | Назначение |
|---|---|
| **Обзор** | Паспорт компьютера и сведения о Windows, CPU, RAM, GPU и накопителях. |
| **Твики** | Каталог параметров, поиск, категории, определение состояний и добавление в очередь. |
| **Твикопедия** | Офлайн-справочник, сформированный из тех же YAML-данных, что и каталог. |
| **Очередь** | Проверка выбранных изменений и пакетное применение. |
| **История** | Журнал транзакций, детали операций и возврат сохранённых значений. |
| **Настройки** | Режим отладки и доступ к журналам сеансов. |
| **О программе** | Версия, стек, библиотеки и благодарности авторам исходных проектов. |

## Поддерживаемые системы

| Параметр | Поддержка |
|---|---|
| ОС | Windows 10 и Windows 11 |
| Архитектура | x86-64 / AMD64 |
| ARM64 | Не поддерживается |
| Формат | Portable, один `Tweakopedia.exe` |
| Установка | Не требуется |
| Интерфейс | Русский язык, светлая тема |

Конкретный твик может иметь собственный минимальный или максимальный номер
сборки. Такие ограничения хранятся в YAML и проверяются до добавления изменения
в план.

## Запуск

Готовый выпуск состоит из одного файла:

```text
Tweakopedia.exe
```

1. Поместите файл в любой удобный каталог.
2. Запустите `Tweakopedia.exe` обычным способом.
3. При первом запуске контейнер извлечёт Qt-runtime в локальный кэш пользователя.
4. Повышение прав запрашивается только при запуске Executor для применения или
   возврата системных изменений.

После локальной сборки готовый файл находится здесь:

```text
D:\ChatGPT\Projects\Tweakopedia\dist\Tweakopedia.exe
```

## Сборка из исходников

### Требования

- Windows 10 или Windows 11 x64;
- Git;
- PowerShell 7 (`pwsh`);
- Python 3 для первоначальной установки `aqtinstall`;
- доступ к репозиториям Qt и GitHub при первом развёртывании toolchain.

Версии инструментов зафиксированы в
[`tools/toolchain-lock.json`](tools/toolchain-lock.json):

| Компонент | Версия |
|---|---:|
| Qt | 6.8.3 |
| MinGW | 13.1.0 |
| CMake | 3.30.5 |
| Ninja | 1.12.1 |
| aqtinstall | 3.3.0 |

### Подготовка окружения

```powershell
git clone https://github.com/noteMASTER11/Tweakopedia.git D:\ChatGPT\Projects\Tweakopedia
Set-Location D:\ChatGPT\Projects\Tweakopedia
pwsh -NoProfile -File .\tools\bootstrap-toolchain.ps1
```

Скрипты проекта намеренно используют каталоги `D:\ChatGPT\Tools`,
`D:\ChatGPT\Cache` и `D:\ChatGPT\Temp`. Пакетный сценарий также проверяет, что
выпуск создаётся в `D:\ChatGPT\Projects\Tweakopedia\dist`. Для другой структуры
каталогов потребуется изменить `CMakePresets.json`, `tools/toolchain-lock.json`
и проверки путей в `tools/package.ps1`.

### Debug-сборка

```powershell
pwsh -NoProfile -File .\tools\build.ps1 -Preset mingw-debug
```

Основные исполняемые файлы появятся в подкаталогах
`build\mingw-debug\apps`.

### Release-сборка и единый EXE

```powershell
pwsh -NoProfile -File .\tools\package.ps1 -Preset mingw-release
```

Сценарий выполняет чистую Release-сборку, разворачивает Qt-runtime, добавляет
контент и лицензии, создаёт payload, проверяет контейнер и публикует ровно один
файл в `dist`.

## Тестирование

Полный набор тестов:

```powershell
pwsh -NoProfile -File .\tools\test.ps1 -Preset mingw-debug
```

Запуск выбранной группы CTest:

```powershell
pwsh -NoProfile -File .\tools\test.ps1 -Preset mingw-debug -Regex QmlPlanPreviewHistory
```

Проверка однофайлового выпуска:

```powershell
pwsh -NoProfile -File .\tests\package\PackageLayoutTest.ps1 `
  -PackagePath D:\ChatGPT\Projects\Tweakopedia\dist
```

Текущая ветка содержит 70 CTest-сценариев. Они покрывают:

- загрузку и проверку YAML-каталога;
- совместимость и определение текущих состояний;
- построение очереди и плана;
- работу с реестром, деревьями реестра, AppX, Feature Store, планировщиком,
  BCD, схемами питания и компонентами Windows;
- протокол GUI ↔ Executor;
- транзакционные файлы и SQLite;
- bootstrap, manifest, ZIP-payload и runtime-кэш;
- QML-компоненты и пользовательские сценарии;
- сквозной вертикальный срез.

Для детерминированных снимков интерфейса используется
`TweakopediaVisualCapture`. Готовые QML-сцены находятся в `tests/visual`.

## Архитектура

Однофайловый выпуск содержит три исполняемых компонента:

```text
Tweakopedia.exe
├── Bootstrap
│   ├── проверяет footer, manifest и SHA-256 payload
│   ├── подготавливает версионированный runtime-кэш
│   └── запускает GUI
├── Tweakopedia.App.exe
│   ├── Qt Quick / QML-интерфейс
│   ├── каталог, Твикопедия, очередь и история
│   └── работает без постоянного повышения прав
└── Tweakopedia.Executor.exe
    ├── получает типизированный план по локальному IPC
    ├── создаёт снимок транзакции
    └── применяет или возвращает поддерживаемые операции
```

Поддерживаемые типы операций:

- чтение, запись и удаление значений реестра типов `DWORD`, `QWORD`, `SZ`,
  `EXPAND_SZ`, `MULTI_SZ` и `BINARY`, включая значения по умолчанию;
- ограниченные снимки, удаление и точное восстановление деревьев реестра;
- изменение пользовательской конфигурации Windows Feature Store;
- удаление обнаруженных AppX-пакетов текущего пользователя;
- включение и отключение существующих задач планировщика;
- изменение разрешённых элементов BCD и индексов AC/DC схемы питания;
- включение и отключение Optional Features и Capabilities Windows;
- управляемые файловые операции с фиксированным назначением.

GUI не передаёт Executor произвольную строку PowerShell или CMD. План содержит
только известные типы операций, целевые объекты, ожидаемые fingerprints и
требование перезапуска.

## Структура репозитория

```text
apps/
  bootstrap/       загрузчик единого EXE-контейнера
  executor/        отдельный процесс применения изменений
  packager/        сборщик контейнера
  tweakopedia/     Qt Quick-приложение и QML-интерфейс
assets/            логотип, иконка и Win32-ресурсы
cmake/             зависимости и развёртывание Qt
content/
  categories.yaml  дерево категорий
  apps.json        метаданные удаляемых приложений
  tweaks/          YAML-определения твиков и тексты Твикопедии
docs/              спецификации, планы и результаты проверок
licenses/          уведомления о сторонних компонентах
src/
  app/             модели и контроллер приложения
  content/         загрузка и проверка каталога
  detection/       совместимость и определение состояния
  domain/          доменные типы
  execution/       план, IPC и исполнители операций
  package/         контейнер и runtime-кэш
  persistence/     SQLite и файлы транзакций
  planning/        очередь и построение плана
  platform/        Win32, WMI, DXGI, AppX и Feature Store
tests/             unit-, QML-, интеграционные и пакетные тесты
tools/             установка toolchain, сборка, тесты и упаковка
```

Каждый твик имеет постоянный уникальный `id`. Пользовательское создание твиков
через интерфейс не предусмотрено; каталог развивается через проверяемые YAML-файлы
в репозитории.

## Хранение данных

Пользовательские данные находятся в `%LOCALAPPDATA%\Tweakopedia`:

```text
%LOCALAPPDATA%\Tweakopedia\
├── Data\
│   ├── tweakopedia.db
│   ├── logs\
│   └── transactions\
└── Runtime\
    └── <SHA-256 payload>\
```

- `tweakopedia.db` хранит историю транзакций.
- `transactions` содержит планы, снимки исходных значений и результаты.
- `Runtime` содержит извлечённую версию приложения и Qt-библиотеки.
- Повторный запуск использует готовый кэш, если manifest и хеши совпадают.
- Свободные устаревшие версии runtime удаляются автоматически; используемая
  другим процессом версия сохраняется до следующего запуска.

## Технологии и зависимости

### Основной стек

- C++20;
- Qt 6.8.3: Core, GUI, QML, Quick, Quick Controls 2, Concurrent, Network и SQL;
- Qt SQL/QSQLITE и SQLite;
- YAML-каталог и Qt Resource System;
- CMake и Ninja;
- MinGW-w64.

### Сторонние библиотеки

| Компонент | Версия | Назначение |
|---|---:|---|
| [yaml-cpp](https://github.com/jbeder/yaml-cpp) | 0.8.0 | Загрузка YAML-каталога. |
| [nlohmann/json](https://github.com/nlohmann/json) | 3.12.0 | Manifest однофайлового контейнера. |
| [miniz](https://github.com/richgel999/miniz) | 3.1.2 | Создание и извлечение ZIP-payload. |
| Qt SQLite driver | Qt 6.8.3 | Локальная база истории. |
| SF Pro | встроенный ресурс | Типографика интерфейса. |

### Интеграция с Windows

- Win32 Registry API / Advapi32;
- WMI через COM, Ole32, OleAut32 и Wbemuuid;
- DXGI для корректного определения видеопамяти;
- DWM для оформления окна;
- CNG/Bcrypt для SHA-256;
- Shell32, Secur32 и NTDLL;
- AppX через PowerShell;
- внутренние API Windows Feature Store.

## Ограничения версии 0.9.3

- Поддерживается только x64; ARM64 и 32-разрядные выпуски приложения не
  собираются.
- Интерфейс пока только русскоязычный и светлый.
- Проект не содержит механизма онлайн-обновления приложения или каталога.
- Автоматический возврат удалённого AppX-пакета не реализован.
- Для части параметров поддержка зависит от редакции и конкретной сборки Windows.
- 72 заголовка документации Winaero не включены: в доступном описании не было
  однозначного исполняемого объекта и значения.
- Изменения офлайн-куста `HKU\Default`, удаление деревьев без восстановимого
  содержимого и параметризованные команды питания не импортируются.
- Управление службами, очистка пользовательских данных и произвольные сценарии
  намеренно не входят в каталог.
- Некоторые изменения требуют выхода из учётной записи, перезапуска службы или
  перезагрузки компьютера.
- Цифровая подпись выпуска пока не настроена.
- Build-скрипты версии 0.9.3 привязаны к принятой структуре каталогов на диске `D:`.
